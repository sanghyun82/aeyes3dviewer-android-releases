# AEYES 3D Viewer Android

[정식 1.6.0 설치 APK 다운로드](https://github.com/sanghyun82/aeyes3dviewer-android-releases/releases/download/android-v1.6.0-13/AEYES-3D-Viewer-android-stable-13.apk)

휴대폰과 태블릿에서 같은 APK를 사용합니다. Android 8.0 이상을 지원합니다.
정식 배포에는 운영 인증서로 서명한 설치 APK 하나만 제공합니다.

설치 후 앱의 라이선스 메뉴에서 신청하고 담당자 승인을 받아 사용하세요.

## 기존 시험 앱에서 전환

정식 앱 ID는 `kr.co.aeyes.viewer3d`입니다. 기존 1.5.x 시험 앱(`com.example.aeyes3dviewer`)과는 별도로 설치됩니다.
변경한 STEP 파일을 공유 Documents에 저장한 뒤 정식 앱에서 다시 열어 주세요.
새 앱의 라이선스 신청·승인이 필요하며, 개인 설정·최근 파일·사용자 재질 목록은 자동 이전되지 않습니다.
